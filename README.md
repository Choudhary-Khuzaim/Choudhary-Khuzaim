## ⚡ About Me

<img align="right" width="340" src="https://cdn.dribbble.com/users/1162077/screenshots/3848914/programmer.gif" alt="Coding Animation" />

I am a **Software Engineering graduate from KIET** and a **Senior Software Developer at Hashmi Innovations**, specializing in architecting scalable mobile applications, modern full-stack web platforms, and interactive 3D experiences. Driven by clean architecture, high-performance engineering, and user-centric UI/UX design, I build production-ready software systems from the ground up.

> 🎯 **Current Focus:** Leading end-to-end mobile and full-stack product engineering, optimizing cloud-native microservices, and crafting high-performance cross-platform applications.

- 📱 **Mobile Engineering:** Extensive production experience with **Flutter, Dart, Swift (iOS Native with SwiftUI/MVVM), and React Native** to deliver seamless cross-platform and native apps.
- 🌐 **Full-Stack Web:** Architecting responsive, high-speed web applications and RESTful APIs utilizing **Next.js, React, Tailwind CSS, Node.js, Express, and Python**.
- 🎮 **Game Development:** Designing and developing engaging 3D interactive mechanics and arcade experiences using **Unity 3D and C#**.
- ☁️ **DevOps & Databases:** Hands-on expertise with containerization, Linux environments, and scalable databases including **Docker, PostgreSQL, MongoDB, Cloud Firestore, and Firebase**.
- 🤖 **AI & Data Workflows:** Built **"Rahzaan,"** an agentic AI-driven career counseling platform, utilizing **FastAPI, Pandas, NumPy, Scikit-learn, and NLTK**.

### 🎖️ Leadership & Community
Served as the **Class Representative** for my Software Engineering cohort at KIET (2022–2026), bridging communication between students and faculty, leading technical groups, and managing academic initiatives from the first semester through graduation.
